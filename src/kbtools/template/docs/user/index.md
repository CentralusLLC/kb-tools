# User documentation

Documentation for the people who use {{PROJECT}}: guides, how-tos, reference and FAQs.
It lives here, in the knowledge base, so every person and agent can see it and keep it
current. It can also be published on its own (for example with a static site generator)
because it is written for users, not for the team.

## Rules

- Write for users: their goals and words (see [Audience](../business/audience.md) and the
  [glossary](../domains/glossary.md)), not internal design.
- Pages are `type: User Guide`; screenshots are figures in `user/assets/` with alt text.
- With several apps, use one subfolder per app (`user/<app>/`).
- A change that users will notice updates these pages in the same pull request
  ([Definition of done](../process/work-tracking.md#definition-of-done)).
