# Design

How {{PROJECT}} looks and behaves for its users: user flows, screens and the design
system. Brand identity is in [Branding](../business/branding.md); technical design for an
epic is in its `plan.md` ([Work tracking](../process/work-tracking.md)).

- [Design system](design-system.md): visual and interaction building blocks.

## Adding design pages

- One page per user flow or screen group (`type: Design`), linked from this index.
- Screens and wireframes are figures in `design/assets/`, each with an element table
  ([Figures](../conventions.md#figures)); flows are Mermaid diagrams with node and edge tables.
- Link each flow to the epics and items that build it, and to the personas it serves
  ([Audience](../business/audience.md)).
