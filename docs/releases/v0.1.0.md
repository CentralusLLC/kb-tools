# v0.1.0

The first release. It gives a project repository a scaffolded knowledge base and the
commands to ingest documents, plan work and check conventions, from a laptop or as an MCP
sidecar for Paperclip agents. Ported from the client-project extraction tools.

## Added

- `kb scaffold`: generic knowledge-base template (agent files, OKF `docs/` sections, process pages,
  definition of done, PR template, intake folders, `tools/kb`); never overwrites.
- `kb init`, `kb inventory`, `kb log`: git-ignored sources with `ingest-log.csv` (hash, origin, status, outputs).
- `kb extract`: text, LibreOffice renders of every page or slide, PowerPoint structure (positions,
  tables, charts, notes, glued connectors), Excel formulas and cached values, media, manifest, review checklist.
- `kb figure`: crop key graphics into `docs/**/assets/` with a Markdown snippet and element table.
- `kb check`: ingest log, OKF front matter, links, images, diagram element descriptions, work tree, catalog freshness.
- `kb report`: verification tier, recency and flags per page.
- `kb catalog`: generated `docs/catalog.md` and filtered md/json/jsonl output.
- `kb work`: epics, plans and items (kinds, statuses, dependencies), roadmap, acceptance and retrospective checks.
- `kb serve`: MCP server exposing the commands as `kb_*` tools, restricted to allowed roots.
- Docker image with LibreOffice and Office-compatible fonts.
