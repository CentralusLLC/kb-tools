# Domains

Domain knowledge about kb-tools's subject matter: concepts, rules, entities and processes.
Each topic is a sub-wiki, a directory with its own `index.md`, so it can grow independently.

- [Glossary](glossary.md): term definitions. Use these terms in code, docs and UI.

> TODO: Add sub-wikis for the main topics.

## Adding a sub-wiki

1. Create `domains/<topic>/` with an `index.md` listing its pages.
2. Add an `Overview` page for the topic, and `Domain Concept` pages for its concepts.
   Put figures in `domains/<topic>/assets/`.
3. Link the sub-wiki from this index, and add its terms to the [glossary](glossary.md).
